## ✨ Features

### 🤖 AI Engine
- 🔓 **Dual-Mode AI** — Groq + OpenRouter
- ⚡ **Groq** — Fast, reliable (Qwen 3.8, GPT-OSS models)
- 🔓 **OpenRouter** — Uncensored (Dolphin Mixtral)
- 🔄 **Auto Fallback** — one fails, other takes over
- 🎛️ **Adjustable Temperature** — 0 to 1.5
- 🎯 **Smart Reframe** — sensitive queries auto-reframed
- ⛔ **No-Refusal System** — never says "sorry"

### 🐍 Python IDE
- Write Python directly in browser
- Run with **Skulpt** (WebAssembly)
- Live output panel
- Sample code included
- Tab key support + Ctrl+Enter to run

### 🌐 HTML Live Preview
- Write HTML/CSS/JS
- Instant rendering in iframe
- Fullscreen option
- Sample template included

### 💻 Terminal Emulator
- 25+ commands
- Command history (↑ ↓ keys)
- Tab autocomplete
- Matrix effect, hack animation
- ASCII art banners
- Ask AI directly from terminal

### 🎨 Hacker UI
- Matrix rain canvas background
- Scanline CRT effect
- Glitch animations
- Boot sequence with progress bar
- Dark/Light themes
- Neon green cyberpunk aesthetic

### 🛠️ Utilities
- 📋 One-click code copy
- 💾 Download code as file
- ▶️ Run Python from chat directly
- 🖥️ Preview HTML from chat directly
- 🎤 Voice input (Bengali)
- 📎 File upload (images, code)
- 🔍 Chat search
- 📤 Export chat as Markdown
- ⚙️ Settings panel

## 🚀 Quick Start

### Option 1: Use Live Version
👉 **[Try it live](https://akijelectronic-dev.github.io/nxt-cyber/)**

### Option 2: Deploy Your Own

1. **Clone or download** this repo
2. **Setup Cloudflare Worker** (see below)
3. **Update `WORKER_URL`** in `script.js`
4. **Open `index.html`** in browser — done!
